# Why the buyer acts through an agent

The weekly job is to read outstanding lines, compare dates, record a supplier answer and prepare follow-up work. Those are records and decisions. The CLI and database expose them without a separate editing application.

A browser screen adds shared queues, mobile receipt capture, offline entry and drag-and-drop planning. This base has none of those. The generated HTML is read-only and is not a supplier portal. Local embedded storage is for one operator process at a time. PostgreSQL supports a shared database, but authentication and per-user permissions still need design.

Enterprise DNA builds the screens and connections the business needs. The free base is useful for a buyer running a records-based daily review, with original evidence available separately.
